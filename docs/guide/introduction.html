# What is VuePivottable?

It is a Vue port of the jQuery-based PivotTable.js (opens new window)

# Inspired

  • plotly/react-pivottable (opens new window) - React-based pivot table library
  • David-Desmaisons/vue-plotly (opens new window) - vue wrapper for plotly.js
