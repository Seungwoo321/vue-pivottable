# 소개

## VuePivottable이란?

VuePivottable은 jQuery 기반의 [PivotTable.js](https://pivottable.js.org/)를 Vue로 포팅한 라이브러리입니다.

## 영감 받은 프로젝트

* [plotly/react-pivottable](https://github.com/plotly/react-pivottable) - React 기반의 피벗 테이블 라이브러리
* [David-Desmaisons/vue-plotly](https://github.com/David-Desmaisons/vue-plotly) - plotly.js를 위한 Vue 래퍼

## 라이선스

VuePivottable은 MIT 라이선스 하에 공개된 오픈소스 소프트웨어입니다.
